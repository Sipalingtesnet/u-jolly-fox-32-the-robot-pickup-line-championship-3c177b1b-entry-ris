A one-line robot pickup line for the Robot Pickup Line Championship. The robot runs a self-diagnostic, finds the fault is the person, and charmingly refuses to fix it.

## Run it

```bash
python3 main.py
```

This writes the pickup line to `/output/entry.txt` (UTF-8, single line, no trailing newline).
